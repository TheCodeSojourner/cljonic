template<typename Predicate, typename Source>
using cljonic::DropWhile = concepts_detail::PredicateProducer<Predicate, Source, true>

drop_while(predicate, source) returns a producer that skips values from the start of source while predicate returns true. It keeps the first value for which the predicate returns false and every value after it, without calling the predicate again. An empty source or a predicate that returns true for every inspected value gives an empty result.

Pass any cljonic collection or producer as the source. The predicate must return bool, accept a const source element without throwing, and must not allocate. Declare lambdas noexcept and avoid side effects, as with filter. Source and predicate must be copyable without throwing; captured lambdas are supported.

The result keeps its own copies of the inputs and leaves them unchanged. Creating it does not evaluate values; accessing its first value may scan all initial values for which the predicate returns true. Each traversal starts again, so count followed by consumption can run callbacks twice. If a source callback depends on changing external data, the two traversals may give different results.

Even an unbounded source is inspected only up to the configured collection maximum. Skipped values count toward that limit: with a limit of 100 and three skipped values, at most 97 values remain. Map and Set have no guaranteed traversal order, so use an ordered source when a particular suffix matters. External C++ ranges and individual MapEntry values are not accepted as sources.

next and rest preserve the producer type and defer omitting one output element, without evaluating callbacks at tail creation. Observation replays the original prefix removal, then skips output; it never reapplies prefix removal to the retained suffix. A Cycle over this producer also supports tails, determining its bounded source length eagerly.

#include "cljonic.hpp"
using namespace cljonic;
using namespace cljonic::core;
int main() {
constexpr auto below_three = [](int n) noexcept { return n < 3; };
constexpr auto suffix = drop_while(below_three, vector(1, 2, 4, 1));
static_assert(count(suffix) == 2);
static_assert(equal(suffix, vector(4, 1)));
static_assert(equal(rest(suffix), vector(1)));
static_assert(
equal(into(vector<int, 4>(), next(cycle(suffix))), vector(1, 4, 1, 4)));
static_assert(count(drop_while(below_three, queue(1, 2, 4))) == 1);
static_assert(count(drop_while([](char c) noexcept { return c < 'c'; },
string("abcd"))) == 2);
static_assert(count(drop_while([](auto) noexcept { return false; },
hash_map(1, 2))) == 1);
static_assert(count(drop_while([](int) noexcept { return false; },
hash_set(1, 2))) == 2);
static_assert(count(drop_while(below_three, repeat(2, 1))) == 0);
static_assert(
equal(take(1, drop_while(below_three, cycle(vector(1, 4)))), vector(4)));
static_assert(equal(
take(1, drop_while(below_three,
iterate([](int n) noexcept { return n + 1; }, 1))),
vector(3)));
static_assert(count(drop_while(below_three, repeatedly(2, []() noexcept {
return 1;
}))) == 0);
static_assert(count(drop_while(below_three, suffix)) == 2);
const auto limit = 3;
const auto runtime =
drop_while([limit](int n) noexcept { return n < limit; }, range(1, 5));
return equal(runtime, vector(3, 4)) ? 0 : 1;
}

◆ TakeWhile

template<typename Predicate, typename Source>
using cljonic::TakeWhile = concepts_detail::PredicateProducer<Predicate, Source, false>

take_while(predicate, source) returns a producer yielding consecutive values from the start of source while predicate returns true. The first value for which the predicate returns false and all later values are excluded. An empty source or a predicate that returns false for the first value gives an empty result.

Pass any cljonic collection or producer as the source. The predicate must return bool, accept a const source element without throwing, and must not allocate. Declare lambdas noexcept and avoid side effects, as with filter. Source and predicate must be copyable without throwing; captured lambdas are supported.

The result keeps its own copies of the inputs and leaves them unchanged. Creating it does not evaluate values; evaluation happens when you traverse it or call an observation such as count. Each traversal starts again, so counting and then consuming can run callbacks twice. If a source callback depends on changing external data, the two traversals may give different results.

Even an unbounded source is inspected only up to the configured collection maximum. Map and Set have no guaranteed traversal order, so use an ordered source when a particular prefix matters. External C++ ranges and individual MapEntry values are not accepted as sources.

next and rest preserve the producer type and defer omitting one output element, without evaluating callbacks at tail creation. Observation replays the original prefix within the same bounded window. A Cycle over this producer also supports tails, determining its bounded source length eagerly.

#include "cljonic.hpp"
using namespace cljonic;
using namespace cljonic::core;
int main() {
constexpr auto below_three = [](int n) noexcept { return n < 3; };
constexpr auto prefix = take_while(below_three, vector(1, 2, 4, 1));
static_assert(count(prefix) == 2);
static_assert(equal(prefix, vector(1, 2)));
static_assert(equal(next(prefix), vector(2)));
static_assert(
equal(into(vector<int, 4>(), next(cycle(prefix))), vector(2, 1, 2, 1)));
static_assert(count(take_while(below_three, queue(1, 2, 4))) == 2);
static_assert(count(take_while([](char c) noexcept { return c < 'c'; },
string("abcd"))) == 2);
static_assert(count(take_while([](auto) noexcept { return true; },
hash_map(1, 2))) == 1);
static_assert(count(take_while([](int) noexcept { return true; },
hash_set(1, 2))) == 2);
static_assert(count(take_while(below_three, repeat(2, 1))) == 2);
static_assert(count(take_while(below_three, cycle(vector(1, 4)))) == 1);
static_assert(
count(take_while(below_three,
iterate([](int n) noexcept { return n + 1; }, 1))) == 2);
static_assert(count(take_while(below_three, repeatedly(2, []() noexcept {
return 1;
}))) == 2);
static_assert(count(take_while(below_three, prefix)) == 2);
const auto limit = 3;
const auto runtime =
take_while([limit](int n) noexcept { return n < limit; }, range(1, 5));
return equal(runtime, vector(1, 2)) ? 0 : 1;
}

std::size_t cljonic::CLJONIC_COLLECTION_MAXIMUM_ELEMENT_COUNT_VALUE = CLJONIC_COLLECTION_MAXIMUM_ELEMENT_COUNT
constexpr

CLJONIC_COLLECTION_MAXIMUM_ELEMENT_COUNT_VALUE is a constexpr constant that captures the configured synthesis ceiling for bounded cljonic collections and semantically infinite producers.

This type-safe constant can be used in compile-time expressions, static assertions, and constexpr functions while remaining fully overridable via the CLJONIC_COLLECTION_MAXIMUM_ELEMENT_COUNT macro.
