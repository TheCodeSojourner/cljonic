Detailed Description

Checked fixed-width numeric free functions.

Arithmetic operands are accepted only when converting or combining them cannot silently lose data: at compile time, integer operands determine a shared return type that can represent every value from both operand types; floating operands must have exactly the same supported floating type, and that type is used as the return type. Boolean, character, byte, enum, pointer, user-defined, and mixed integer/floating operand pairs are rejected. Integer and floating arithmetic reject overflow, underflow, division by zero, and non-finite results.

Every operation with a runtime failure condition has a matching can_* preflight. A false preflight or a runtime failure returns the value-initialized result type, leaving the operands unchanged. For a numeric result type, this value is 0. A failure in required constant evaluation rejects the expression.

Integer division follows Clojure-compatible semantics:

  • div and quot truncate toward zero.
  • rem has the numerator's sign.
  • mod divides and rounds the quotient toward negative infinity, producing a remainder with the denominator's sign.

For example, quot(-7, 3) returns -2, rem(-7, 3) returns -1, and mod(-7, 3) returns 2. The bitwise operations preserve fixed-width representation; shifts outside the value width and overflowing left shifts fail preflight.

add provides Clojure-compatible arities: add<T>() returns T{}, unary add(x) returns x, binary add(x, y) adds two operands, and variadic add(x, y, &more) folds from left to right. can_add provides the corresponding preflight for the same arities.

sub provides unary checked negation sub(x), which returns the negated value of x; binary subtraction sub(x,y), which returns x minus y; and left-to-right variadic subtraction sub(x,y,&more), which folds the operands from left to right. sub() is rejected. can_sub provides the matching preflight for the unary, binary, and variadic forms.

mult provides a typed one identity mult<T>(), which returns the value T{1}; unary identity mult(x), which returns x; binary multiplication mult(x,y), which returns the product; and left-to-right variadic multiplication mult(x,y,&more), which folds the operands from left to right.

div provides a unary floating reciprocal div(x), which returns 1/x; binary division div(x,y), which returns x divided by y; and left-to-right variadic division div(x,y,&more), which folds the operands from left to right. Unary integer division is rejected. can_div provides the matching side-effect-free preflight.
